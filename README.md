# .github

The public profile shown at [github.com/xano-sdk](https://github.com/xano-sdk), and the
org-wide defaults for repositories that do not carry their own.

- `profile/README.md` is the page itself.
- `profile/assets/` holds the light and dark SVGs it shows. They are generated: edit
  `scripts/build-assets.mjs`, then run `node scripts/build-assets.mjs`.
- `.github/ISSUE_TEMPLATE/` and `SECURITY.md` are the default issue forms and security
  policy. A repository with its own `.github/ISSUE_TEMPLATE/` or `SECURITY.md` uses
  that instead.
